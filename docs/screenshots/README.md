# Screenshots

Drop three PNGs here with exactly these names; the main README already points at them.

| File | What to capture |
|---|---|
| `panel-outline.png` | The side panel on the **Outline** tab, after a scan of a real page. |
| `panel-changes.png` | The **Changes** tab, showing a few rows with tag dropdowns. |
| `panel-apply.png` | Just after Apply + Save, with the "✓ saved" status visible. |

How to take them: open a page in the Kirki editor, open the panel, scan, then use
**⌘⇧4 then Space** on macOS and click the panel to capture just that window.
Use the dark theme for consistency, and crop out anything private (site name, client data).
